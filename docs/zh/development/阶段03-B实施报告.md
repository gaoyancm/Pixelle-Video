## 4. 项目、批次与草稿语义

- Project支持创建、读取、更新、稳定分页和幂等归档；默认列表隐藏归档；归档项目不能创建batch。
- Batch只在未归档Project中创建；workflow严格来自现有四项`WORKFLOW_SPECS`；draft PATCH使用条件版本更新；submitted或archived内容不可编辑；归档幂等且不删除事实。
- Item PUT是0..100项完整集合替换。已有ID必须属于当前batch，新项生成稳定ID；最终position唯一；两项互换和多项循环继续使用03-A两阶段临时position语义。
- PUT遗漏的旧draft item仅在无attempt时删除其草稿素材关系和item；任一错误使字段、位置、素材关系和版本全部回滚。
- 生成参数禁止混入priority、`node_id`、workflow key、Provider/Executor或地址字段；优先级公开值`low/normal/high/null`映射为`0/1/2/null`。

## 5. Workflow catalog与预检

Catalog直接遍历`WORKFLOW_SPECS`并从阶段02`MediaJobRequest`参数模型生成公开类型和约束，不维护第二份workflow真相。返回模式、输入素材数量、参数Schema、可用性和安全原因；可用性只读取`media_jobs`开关和配置中匹配的enabled节点，不连接节点。响应不包含JSON文件名、路径、node ID/名称、base URL、Provider/Executor、密钥或提交标识。

Preflight按稳定顺序检查：batch状态和版本、1..100项、workflow、enabled节点、公共参数与override合并、阶段02等价`MediaJobRequest`校验、素材记录/状态/对象可读性/MIME/arity/role、position与有效优先级，最后形成提交可复算快照。issues含稳定`code/message/item_id/position/field`。测试比较前后operation、job、attempt计数及状态，证明preflight只读；节点选择只读配置，Provider调用为0。

## 6. Canonical hash、幂等与单事务

Canonical UTF-8 JSON使用排序键和紧凑编码，覆盖batch ID、workflow、公共参数、调用方版本、按position排序的item ID/position、override、冻结effective parameters、素材ID/role/position、默认/覆盖/有效priority及固定item limit 100；排除时间戳、对象地址、节点瞬态和字典插入顺序。

Submit先按`batch + batch_id + batch_submit + 原始Idempotency-Key`读取`management_operations`。它是唯一幂等事实源：同hash在submitted后仍验证完整事实并重放稳定`result_json`；异hash返回409。operation ID、job ID和job幂等键由batch、item、原始键和canonical hash确定性、作用域化派生，解决真正并发时不同调用者各自产生随机结果身份的问题。

首次路径在事务外完成Schema、节点选择和受管对象读取；短事务内重新条件核验batch/version和资产DB状态，先创建并flush全部parent jobs，再写全部job-asset关系、attempt=1、effective parameter快照、batch submitted/version/item limit和operation结果，最后一次commit。事务内没有HTTP、Provider、ComfyUI、文件写入、sleep或独立子事务。

测试证明：

- 1项I2V：1 operation、1 job、1 input relation、1 attempt，priority和node绑定正确；
- 100项T2V：一次提交创建精确100 job和100 attempt，job键全局唯一且长度安全；
- commit前失败：operation/job/relation/attempt均为0，item快照为空，batch仍draft且版本不变；
- 同键同hash强制同步并发：仅一组job，两个调用收敛到同一结果；
- 同键异hash强制同步并发：一方成功、一方冲突，仅一组事实；
- commit返回未知：完整事实分类为成功；operation不存在时仅安全重试一次；缺失或矛盾事实返回`submission_indeterminate`，不补猜、不重复创建。
