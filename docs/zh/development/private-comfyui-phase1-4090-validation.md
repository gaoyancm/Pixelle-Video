## 联调发现与修复

第一次图片上传返回 HTTP 502，任务没有提交，GPU 队列保持为空。原因是 HTTPX
默认继承了本机环境代理，回环端口转发的 POST 请求被代理截获。

适配器客户端改为 `trust_env=False` 后：

- `POST /upload/image`：HTTP 200
- `POST /prompt`：HTTP 200
- `/history/{prompt_id}` 与 `/queue`：状态查询成功
- `/view`：输出下载成功
